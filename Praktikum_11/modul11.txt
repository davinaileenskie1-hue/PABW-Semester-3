D. Dasar Teori 
a. Apa Itu REST API? 
REST API (Representational State Transfer Application Programming Interface) adalah cara 
aplikasi saling bertukar data melalui protokol HTTP. Client (misalnya Postman, aplikasi React, 
atau aplikasi Android) mengirim request ke sebuah alamat (endpoint), lal u server membalas 
dengan response berformat JSON. Bayangkan REST API seperti pelayan restoran: client memesan 
(request), pelayan meneruskan ke dapur (server), lalu pelayan membawa kembali makanan 
(response).

d. Validasi, Autentikasi, dan Token 
• Validasi memastikan data yang dikirim client sesuai aturan, misalnya judul tidak boleh kosong. 
Di Laravel, aturan validasi ditulis pada Form Request. 
• Autentikasi (authentication) memastikan siapa pengguna yang sedang mengakses, misalnya 
melalui login. 
• Otorisasi (authorization) menentukan apa yang boleh dilakukan pengguna, misalnya hanya 
pemilik artikel yang boleh mengubah artikelnya. 
• Password hashing menyimpan kata sandi dalam bentuk acak (hash), bukan teks asli, 
menggunakan Hash::make(). 
• Token Sanctum adalah "kartu akses" yang diberikan setelah login. Token dikirim pada setiap 
request melalui header berikut: 
Authorization: Bearer <token> 
 
e. HTTP Status Code 
Kode Nama Arti Sederhana 
200 OK Permintaan berhasil 
201 Created Data baru berhasil dibuat 
401 Unauthorized Belum login atau token tidak valid 
403 Forbidden Sudah login, tetapi tidak punya izin 
404 Not Found Data tidak ditemukan 
409 Conflict Data bentrok, misalnya email sudah 
terdaftar 
422 Unprocessable Content Data gagal validasi 
500 Internal Server Error Terjadi error di server 
 
f. Upload File dan multipart/form-data 
Data teks biasanya dikirim dalam format JSON. Namun, JSON tidak dapat membawa file 
seperti gambar atau PDF. Untuk mengirim file, client memakai format multipart/form -data, yaitu 
request yang terdiri dari beberapa bagian: field teks (misalnya title dan cont ent) dan field file. Di 
Postman, format ini dipilih melalui Body → form-data. 

===PAGE===

 
 
• Laravel membaca file dengan $request ->file('file') lalu menyimpannya ke folder storage 
menggunakan method store(). 
• Validasi file memakai aturan file, max (ukuran maksimal dalam KB), dan mimes (jenis file 
yang diizinkan). 
• Method spoofing: PHP hanya membaca file pada request POST. Karena itu, perubahan data 
yang membawa file dikirim dengan method POST ditambah field _method=PATCH, lalu 
Laravel memperlakukannya sebagai PATCH.

Langkah 13 – Menulis Kode CRUD pada PostController 
• Buka app/Http/Controllers/PostController.php, lalu ganti seluruh isinya menjadi: 
<?php 
 
namespace App\Http\Controllers; 
 
use App\Models\Post; 
use Illuminate\Http\Request; 
 
class PostController extends Controller 
{ 
    // GET /api/posts - semua artikel 
    public function index() 
    { 
        return response()->json(Post::latest()->get()); 
    } 
 
    // POST /api/posts - tambah artikel 
    public function store(Request $request) 
    { 
        $post = Post::create($request->only(['title', 'content'])); 
        return response()->json($post, 201); 
    } 
 
    // GET /api/posts/{id} - satu artikel 
    public function show($id) 
    { 
        return response()->json($this->findPost($id)); 
    } 
 
    // PATCH /api/posts/{id} - ubah artikel 
    public function update(Request $request, $id) 
    { 
        $post = $this->findPost($id); 
        $post->update($request->only(['title', 'content'])); 
        return response()->json($post); 
    } 
 
    // DELETE /api/posts/{id} - hapus artikel 
    public function destroy($id) 
    { 
        $this->findPost($id)->delete(); 
        return response()->json(['message' => 'Post berhasil dihapus']); 
    } 
 
    // Mencari artikel, jika tidak ada kirim 404 
    private function findPost($id) 
    { 
        $post = Post::find($id); 
        if (! $post) {

            abort(404, 'Post tidak ditemukan'); 
        } 
        return $post; 
    } 
}

Langkah 23 – Menulis Method register() 
• Buka app/Http/Controllers/AuthController.php, lalu ganti isinya menjadi: 
<?php 
 
namespace App\Http\Controllers; 
 
use App\Http\Requests\RegisterRequest; 
use App\Models\User; 
use Illuminate\Support\Facades\Hash; 
 
class AuthController extends Controller 
{ 
    public function register(RegisterRequest $request) 
    { 
        $data = $request->validated(); 
 
        // Cek email sudah dipakai atau belum 
        if (User::where('email', $data['email'])->exists()) { 
            return response()->json(['message' => 'Email sudah terdaftar'], 409); 
        } 
 
        $user = User::create([ 
            'name'     => $data['name'], 
            'email'    => $data['email'], 
            'password' => Hash::make($data['password']), // password di-hash 
        ]); 
 
        return response()->json([ 
            'message' => 'Registrasi berhasil', 
            'user'    => $user->only(['id', 'name', 'email']), 
        ], 201); 
    } 
}

Langkah 28 – Menambahkan Method login(), me(), dan logout() 
• Pada AuthController.php, tambahkan import berikut di bagian atas: 
use App\Http\Requests\LoginRequest; 
use Illuminate\Http\Request; 
 
 
• Tambahkan tiga method berikut di dalam class AuthController (di bawah method register): 
public function login(LoginRequest $request) 
{ 
    $data = $request->validated(); 
    $user = User::where('email', $data['email'])->first(); 
 
    // Cek email dan password 
    if (! $user || ! Hash::check($data['password'], $user->password)) { 
        return response()->json(['message' => 'Email atau password salah'], 401); 
    } 
 
    $token = $user->createToken('api-token')->plainTextToken; 
 
    return response()->json([ 
        'message'      => 'Login berhasil', 
        'token_type'   => 'Bearer', 
        'access_token' => $token, 
        'user'         => $user->only(['id', 'name', 'email']), 
    ]); 
} 
 
public function me(Request $request) 
{ 
    return response()->json($request->user()->only(['id', 'name', 'email'])); 
} 
 
public function logout(Request $request) 
{ 
    $request->user()->currentAccessToken()->delete(); 
    return response()->json(['message' => 'Logout berhasil']); 
}

    if ($request->hasFile('file')) {

// PATCH /api/posts/{id} - ubah artikel 
// Jika mengirim file, gunakan POST + field _method=PATCH 
public function update(UpdatePostRequest $request, int|string $id): JsonResponse 
{ 
    $post = $this->findOwnedPost($request, $id); 
    $data = $request->safe()->only(['title', 'content']); 
 
    if ($request->hasFile('file')) { 
        // Ganti file lama dengan file baru 
        $this->deleteFile($post); 
        $data = [...$data, ...$this->storeFile($request->file('file'))]; 
    } elseif ($request->boolean('remove_file')) { 
        // Hapus lampiran tanpa mengganti 
        $this->deleteFile($post); 
        $data = [...$data, 'file_path' => null, 'file_name' => null]; 
    } 
 
    $post->update($data); 
 
    return response()->json($post); 
}

public function destroy(Request $request, int|string $id): JsonResponse 
{ 
    $post = $this->findOwnedPost($request, $id);

    $post->delete();

public function file(int|string $id): StreamedResponse 
{ 
    $post = $this->findPost($id); 
 
    if (! $post->file_path || ! Storage::disk('local')->exists($post->file_path)) { 
        abort(404, 'File tidak ditemukan'); 
    } 
 
    // inline = gambar / PDF langsung dibuka di browser 
    return Storage::disk('local')->response($post->file_path, $post->file_name, [],

}
